# Power BI Dashboard

This folder contains the Power BI report for the Airline Customer Experience Analytics project.

The dashboard analyses synthetic passenger journey data from July 2025 to June 2026, covering customer satisfaction, flight delays, disruptions, complaints, service recovery, and route performance.

## Report file

`Airline_Customer_Experience_Analytics.pbix`

## Dashboard pages

1. Executive Overview
2. Flight Disruption & Delay Analysis
3. Customer Complaints & Service Recovery
4. Passenger Experience & Segmentation
5. Route Performance & Customer Impact

**Note:** All data is synthetic and does not represent actual airline or passenger performance.
