# Python Analysis

This folder contains Python scripts for data inspection, validation, statistical analysis and visualisation for the Airline Customer Experience Analytics project.

## Analysis areas
- Flight disruption and delay analysis
- Complaint and baggage analysis
- Cabin-class and passenger segmentation
- Multivariable analysis and complaint risk
- Data quality checks and validation
- Customer experience visualisations
- Data preparation for Athena workflows

All datasets in this portfolio project are synthetic.
