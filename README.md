# Airline Customer Experience Analytics

## Project Overview

An end-to-end analytics portfolio project exploring airline customer experience using Power BI, Python and SQL. The project analyses 50,000 synthetic passenger journeys to identify patterns in customer satisfaction, flight delays, disruptions, complaints and route performance.

## Business Objectives

- Measure customer satisfaction, complaint rates and disruption rates.
- Investigate how delay severity relates to passenger satisfaction and complaints.
- Compare journey volumes and customer outcomes across routes.
- Analyse service-case resolution, case status and compensation.
- Translate findings into actionable business recommendations.

## Dataset

The project uses four synthetic datasets:

| Dataset | Records |
|---|---:|
| Customer Journey | 50,000 |
| Airport Reference | 27 |
| Flight Schedule | 29,200 |
| Service Cases | 878 |

**Reporting period:** July 2025 – June 2026.

*These datasets are synthetic and do not represent actual airline or passenger performance.*

## Tools and Technologies

- **Power BI:** Interactive dashboards, KPI reporting and data visualisation.
- **DAX and Power Query:** Measures, data transformation and reporting logic.
- **Python:** Data inspection and statistical analysis.
- **SQL:** Data querying and analytical investigation.
- **AWS:** Cloud architecture planned around Amazon S3, AWS Glue Data Catalog and Amazon Athena; implementation status will be documented separately.

## Key Findings

- Average customer satisfaction was approximately **3.74 out of 5**.
- The overall complaint rate was approximately **12.04%**.
- The disruption rate was approximately **12.10%**.
- Journeys delayed by more than 60 minutes had substantially lower satisfaction and higher complaint rates.
- Service-case analysis highlighted open and pending cases that warrant further investigation.
- Route comparisons help identify areas for further investigation, with sample sizes considered before drawing conclusions.

These findings describe patterns in synthetic data and should not be interpreted as causal effects or actual airline performance.
