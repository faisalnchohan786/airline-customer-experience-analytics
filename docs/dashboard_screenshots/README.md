# Power BI Dashboard Screenshots

This folder contains the six dashboard screenshots for the Airline Customer Experience Analytics project.

The screenshots provide static previews of the Power BI report covering:

- Executive overview and key performance indicators
- Flight disruption and delay analysis
- Customer complaints and service recovery
- Passenger experience and segmentation
- Route performance and customer impact
- Executive recommendations and action plan

For the complete project overview, analytical findings, data model, AWS architecture and dashboard previews, see the [main project README](../../README.md).

**Data disclaimer:** All datasets and findings are synthetic and do not represent actual airline performance.
